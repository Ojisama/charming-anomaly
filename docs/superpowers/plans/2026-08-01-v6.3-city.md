# v6.3 "The City gets a city" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the real terrain generator (streets, blocks, curb-snapped furniture) into The City, make traffic drive the street grid while always threatening the player, add telegraphed destructible cover, rework the roster (aerial patrol drones, street rats, blink pigeons), a lane-aware geyser mod, a "dispatch" fiction beat, and rain.

**Architecture:** All balance numbers in `config.js`; sim stays pure (events out); render reads `run`, never mutates. The world seed derives from `_obstacleSeed` (no new RNG draw in `createRun`). Design source: `docs/superpowers/specs/2026-08-01-early-chapters-revamp-design.md` § "v6.3 — The City gets a city" — read it first; every decision there was forced by a named adversarial finding, do not "simplify" one away.

**Tech Stack:** vanilla JS, PixiJS v8, plain-node `test/sim-test.js` (no framework).

## Global Constraints

- **RNG discipline:** `createRun` must consume EXACTLY the same number of `Math.random()` draws as today for every chapter. `stepLanes` must keep 2 draws per lane roll. Any new comparison test reseeds `Math.random = mulberry32(20260714)` inside each run. New test scenarios append at the END of `test/sim-test.js` (Run KK) — never in the middle.
- **Event contract:** every new `run.events.push({type:X})` needs a `case` in render.js `handleEvents` AND an entry (or deliberate silence comment) in `SFX_FOR_EVENT` (main.js), plus a doc line in state.js's doc block.
- **i18n:** every new player-visible English string gets an fr.js entry in the same commit. Mirror existing conventions (check whether roster `name`s are in fr.js before adding those).
- **Commits:** per-task commits with plain descriptive subjects (`chore:` for docs); the final release commit is `v6.3.0: <one plain sentence>` and must be the tip pushed to main (build stamp reads HEAD subject).
- **Module boundaries:** terrain.js imports nothing; config.js re-exports terrain's surface (already re-exports `roadAt`, `blockSnap`, `pickWorldSeed`, `nearestCity`, `CITY_GRID`, `ROAD_MINOR_WIDTH`/`ROAD_MAJOR_WIDTH`); sim imports only config/state.
- After EVERY task: `npm test` → `ALL TESTS PASSED`.

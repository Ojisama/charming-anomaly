# v6.2 "Remaster" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Remaster slice of the early-chapters revamp: make the invisible visible (dropped cast FX, silent shard blink, identity-less shriek, default-textured projectiles), give the two flat melee starters knockback, add body's Toxic Shock anomaly, and land the full bilingual reword (taglines, unlock lines, per-chapter endings, body's immune-vocabulary weapon re-theme).

**Architecture:** Pure additions along existing seams — sim pushes new event types, render adds cases/tints, copy changes live in config.js with every renamed English string's fr.js key moved in the same task (i18n keys ARE the English source strings). No new systems, no save changes.

**Tech Stack:** vanilla JS + PixiJS v8, `test/sim-test.js` (plain node asserts, seeded random, append-only), vite build, chrome-devtools MCP for browser verification.

## Global Constraints

- Balance numbers in config.js only; sim.js pure (events out, no Pixi/DOM); render.js never mutates `run`.
- Test scenarios append at the END of test/sim-test.js (single seeded Math.random stream — order is part of determinism). New run letter: **JJ**.
- i18n discipline (spec reconciliation): renaming an English string ORPHANS its fr.js key — every rename moves the entry to the new key with a fresh French translation; every new player-visible string adds one. French uses tu-form, playful register.
- Weapon/mod **ids never change** (save compatibility) — display `name`/`desc` only.
- Versioned commit at the end: `v6.2.0: …` per repo convention; intermediate commits use plain `feat:`/`fix:` subjects (squashed into the release commit is NOT the convention here — each task commits, the final commit is the version stamp).
- Never `git stash`; push `beyond-planet-sphere` then `beyond-planet-sphere:main` at the very end only (deploy = push to main).
